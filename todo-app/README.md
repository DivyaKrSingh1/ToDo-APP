# To-Do List Application

## Created Using
- React
- Vite
- JavaScript
- CSS

## How to Run

1. Clone the repository
   git clone <your-repo-link>

2. Navigate to project folder
   cd todo-app

3. Install dependencies
   npm install

4. Run the app
   npm run dev

## Features
- Add tasks
- Delete tasks
- Mark tasks as completed
- Edit existing tasks
